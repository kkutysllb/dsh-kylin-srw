## 1. 这个插件到底是什么（给下一位维护者的 1 页）

### 1.1 产品命题

不做第二个 Mimir，做 **DSH 桌面端 + 麒麟 Web 端双通道**的科研工作台：**读**（段落锚定、可校验的双语精读产物）+ **写**（按刊物分级的 LaTeX 生产线）+ **证**（每个图/表/数字/公式都能指回真实产物）。差异化三把尖刀：逐段双语精读、刊物分级的诚实性三件套、素材真实性证明链。

### 1.2 技术形态

- 单 npm 包，package.json 同时声明 dsh 与 qilin 两键，共用 cordis.patch.yml；Host 侧零 @deepseek-ai/* 运行时 import；Client 侧只 require 白名单客户端包。
- 装配根 src/index.ts：打开 srw 服务 → 注入 systemPrompt 能力通告 → 注册 4 个技能 → 为根 Agent 挂 5 个工具 → tools/pre-execute 审批钩子 → 注册 RPC /dsh-kylin-srw → 逆序回收。
- 数据模型：**文件是真相源**（项目目录内的 .srw/*.json + literature/ + reading/ + paper/）；storageDomain 只存「哪个根、当前项目、项目投影」。
- 对外面：5 个 Agent 工具 / 35 个动作、47 个 RPC case、4 个技能、单面板 8 张卡（项目头/项目列表/流水线/文献/订阅/精读/论文/诊断）。
- 两条纪律：**agent 车道**（正文/翻译/大纲由会话 Agent 做，插件只做 IO + 门 + 编译，零私有 LLM 调用）；**fail-closed 安全**（路径 containment、SSRF 四步 + 钉 IP、RPC 同源栅栏、永不读第三方 credentials.enc）。

## 3. 真正确认可用的资产（不要重做）

1. **M4 精读是完成度最高的模块**：块级基底层（source_map + srcHash）与呈现层（paragraphs）分离；稳定 ID + 哈希迁移；术语硬约束；paper.md 三态校验；译注版 PDF 体例；真 vaswani 15 页/99 块活体验收，手改源文一个词校验灯翻转。**这是项目最值钱的技术资产。**
2. **刊物诚实性三件套**：venue schema 强制 confidence + sources；unverified 只 warn；pass=undefined 表示「事实缺失 ≠ 不通过」。这是真机制，不是 PPT。
3. **G1 门硬编码在服务层**（sectionWrite → assertConfirmed），不是提示词请求；工具描述同时写纪律。
4. **SSRF 四步 + 钉死 IP + 域名白名单**；**fail-closed 路径护栏**；**RPC 同源栅栏**；**双通道 40+ 条冒烟断言**。
5. **宿主事实已打穿**：远程 125-64-108-97 可达（WSL2，32C/62G）；/usr/lib/wsl/lib/nvidia-smi 可见 2×RTX 4090（24,564 MiB/卡，driver 617.42，cc 8.9）；CUDA 13.4.92；conda base Python 3.14.7 + pip + numpy；pypi 200；ControlMaster 复用返回 CM_REUSE_OK。**这些是 M7 能开工的硬前提，今天已成立。**
6. **工程纪律与可维护性**：一任务一提交、实施实录含勘误、质量门全绿、lossless JSON 回归门、文档记录「为什么」。11k 行里没有明显的为快而乱写。
7. **lib 与 src 同步、构建可复现**：隔离重建后 sha256 相同；测试 163/163、smoke 全 PASS、负例 4/4 变红。

### 5.3 写专利：现有架构完全未覆盖的 1/5

**为什么必须单列**：README/0102 的 R1–R8 没有专利；0102「不做清单」也没让渡；0201 的 75–114 人日预算不含专利。所以「M0–M8 交付 = 完成」的隐含判断不成立。

**法务口径（03 报告 §2，均为官方页面，实施前需代理人复核）**：
- 申请文件：请求书、说明书、权利要求书、说明书摘要；必要时附图（专利法第 26 条）。
- 说明书五部分：技术领域/背景技术/发明内容/附图说明/具体实施方式；段号 [0001]；附图连续编号；权利要求前序+特征部分；一项发明一个独立权利要求；多项从属只能择一引用且不得作为另一项多项从属的基础；摘要 ≤300 字。
- **公开杀死新颖性**：现有技术 = 申请日前国内外为公众所知；宽限期仅 6 个月且只有四种情形；「规定的学术会议」仅指国务院主管部门或全国性学术团体组织，绝大多数国际会议不算。→ 默认**先申请、后公开**。
- 职务发明申请权归单位；在中国完成的发明向外国申请须先做保密审查（专利法第 19 条）。
- 检索源：CNIPA PSS 无公开 API（412）；Google Patents 无官方检索 API；EPO OPS 有 OAuth2 但本环境 403；WIPO 有限 SOAP；商业库需许可。→ MVP 对比文件表**必须支持手工录入**，检索适配器只是增强；不抓取、不绕过 ToS。

**设计**（03 报告 §3–§8）：
- 新域 src/patent/ + 里程碑 M9 + 需求 R9；项目目录 .srw/patent/<id>/（patent.json、disclosure.json、prior-art/references.json、claims.json、spec.json、figures/、formal-check.json、evidence/links.json、filing/、events.jsonl）。
- 工作流 S0–S10：立项/公开盘点 → 交底（G-P0）→ 检索 → 对比文件+特征对比（G-P1）→ 权利要求树（G-P2）→ 特征-支撑矩阵（G-P3 100%）→ 说明书+附图 → 形式检查 F-01…F-19（G-P4 0 error）→ 导出 DOCX/PDF + manifest（G-P5 人工复核）→ 手工回填申请号（G-P6）→ OA 答复（P2）。
- **公开时序门**：论文投稿/预印本上传前调用 patent.publication.check，返回 safe/grace/risk/blocked；默认先申请后公开；risk 红标，技能禁止建议投稿，除非用户显式确认已申请或接受风险并留痕。
- 诚实性红线：对比文件必填公开号/公开日/URL/检索时间；有益效果必须回链实验数据/artifact；measured 哈希不符阻断；不编造、不预测授权、不自动提交、不提供法律意见。
- 复用：workspace/路径护栏、RateGate/SSRF、NPL 三源、精读 source-map 哈希、writer 编译模式、venue 的 confidence+sources 三件套；**不复用** outline.json/venue schema/srw_paper 动作。
- 导出：DOCX 主路径 + PDF（TeX/soffice 探测降级）；PDF 缺失必须 EXPORT_UNAVAILABLE，不静默成功。

**完成判据**：03 报告 §9.1 的 10 条全部可执行（fixture 走完 S1–S8、F-01…F-19 负例、删一条支撑即 CLAIM_SUPPORT_MISSING、对比文件缺 pubDate 阻断、公开门 risk、DOCX 必出、静态断言无 LLM/credentials/绝对路径、权限 0600）。

**人日**：报告口径 MVP **45–60**（含面板/DOCX/19 检查/2 技能）；完整版 +50–77。**Lead 校准**：若先做「lite MVP」（无面板、手工对比文件、Markdown/LaTeX + PDF 导出、10 项核心检查），可压到 **15–20 人日**；但专利代理人复核与真实受理仍是外部门槛。建议先做「公开时序门 + 交底书 + 权利要求树」这 3 件（约 8–12 人日），再决定是否全量。

### 5.4 做实验：设计已打穿，代码为零

**现状**：src/compute 不存在；无 srw_experiment、无 experiment.* RPC、无测试/技能；experiments/ 只是 project.ts:17 的空骨架。**但物理前提今天成立**：主机可达（13ms）、2×4090（全路径 nvidia-smi）、driver 617.42、CUDA 13.4、conda+pip+numpy、pypi 200、setsid/nohup/tail/sha256sum/flock 全在、ControlMaster 复用 CM_REUSE_OK。

**两条改变实现的集成事实**：
1. ssh_run 无显式绝对 cwd 时拼 cd '~' && <cmd>；cd 失败后 && 链被跳过，但 ; 后续照跑、整体 exit 0 → **第一条语句被静默跳过**（本次 Lead 实测复现）。任何派发必须显式远端绝对 cwd + 哨兵。
2. ssh_run stdout 默认 256 KiB **静默截断**，且输出投影不暴露截断标记 → ② 级只做短命令；日志续读/产物回传/哈希必须走 ①/③。

**设计**：13 个 src/compute/*；ComputeProvider 三级链（① ControlMaster 零凭据 → ② ctx.tools.execute('ssh_run') 短命令 → ③ 直连私钥）；hosts.json 只读 + 脱敏；submit 用 argv + setsid nohup 脱离会话；lifecycle 7 态（unknown 不假成功）；日志按字节偏移续读 + 末 4KiB 哈希对账；collect 逐文件 sha256；spec 设计门按 D 档。
**数据契约**：run.json、metrics.json、data/registry.json、paper/claims.json。
**完成判据**：04 报告 A1–A8（真机 vecadd → 断线恢复 → 取消 → unknown → claims 篡改 mismatch）。**人日**：26–28（MVP 11–12）。

**纠错**：baseline 报告用 command -v nvidia-smi 判定「GPU 不可见」，属 PATH 口径误判。Lead 实测 /usr/lib/wsl/lib/nvidia-smi 可见 2×4090；正确的探测必须用全路径（E4 已记录 WSL 怪癖）。

### 5.5 补数据：不是「再跑几个实验」，而是一条可对账的闭环

**核心**：缺口模型 → 排期 → 补跑 → 指标归集 → claim 对账 → 素材/论文更新。缺口的四路输入：已确认 spec + D 档阈值、runs 完成度、metrics.missing/失败 run、未 verified 的 claim。

- gaps.json 条目：missing-run/missing-dataset/missing-baseline、missing-metric、missing-stat（显著性/成本）、outlier、failed-run、stale-input、unverifiable；每条带 blockingClaims、estGpuHours、priority、suggestion。
- 规则：缺失不插值、异常保留原值并用中位数/MAD 标 outlier（禁止静默删点）、失败 run 显式计入 n_planned/n_ok、重跑新 runId + parentRunId、数据只增不删。
- 统计：stats.py/mjs + 脚本 sha256 + 种子 + 输入哈希；输出 t/p/CI/effect size；n<3 时显著性 unverifiable，不假 pass。
- 补数据通道（M7 未开工也能用）：materials.metrics.import 校验形状后复制为 experiments/manual/<run>/metrics.json + run.json（source=manual）；证明链照常工作。
- claims.json：正文行内数字/表格单元格 → runIds + metric + reducer + value/tolerance；verified/mismatch/unverifiable 三态；G-M1 阻断 mismatch。

**完成判据**：gaps 的 P0/P1 为空 + 所有 claim verified + 统计可复算 + 从 code.tar.gz + registry 干净重跑指标哈希逐项一致。**人日**：包含在 M7 26–28 内（其中缺口/排期/统计/claims 约 5–6）。

## 6. 统一架构：五目标共享一条证据链

五条线不是五个孤岛，共用同一套「文件即真相源 + 哈希 + 门」：

    literature/（论文/专利 NPL）
          │  source_map + srcHash
          ▼
    reading/（逐段精读、专利文本精读）
          │  idea / spec / disclosure
          ▼
    experiments/ ──► data/registry.json + runs/<id>/metrics.json（sha256）
          │                                   │
          ▼                                   ▼
    materials/manifest.json（图/表/伪代码/公式）  paper/claims.json（行内数字/单元格）
          │                                   │
          └────────────► writer/ ◄────────────┘
                            │
              ┌─────────────┴─────────────┐
              ▼                           ▼
        paper PDF + submission pack   patent/（交底/权利要求/说明书/形式检查）
              │                           │
              └────► 公开时序门 ◄─────────┘
                    （先申请、后公开）

**共享契约**：sha256、四级状态（verified/mismatch/unverifiable/illustrative）、manifest、claims、provenance、G 门（G1/G-M1/G-M2/G-M3/G-P0..G-P6）、人工复核门。
**新增域**：src/materials、src/verify（manifest/recompute/formula-gate/illustrative）、src/compute、src/patent、src/data（或并入 compute）。
**新增工具/RPC/UI**：srw_materials、srw_verify、srw_experiment、srw_patent；materials./verify./experiment./patent.*；素材卡、实验卡、专利卡、投稿卡；技能 materials-proof/experiment-design/repro-audit/patent-search/patent-drafting。

**为什么这样集成**：专利的「有益效果」和论文的「实验结果」是同一批数据；论文的「现有技术」和专利的「对比文件」是同一批文献；精读的块锚可同时服务论文引用与专利特征-支撑。分开建会重复三套证据链，且无法实现「论文公开前检查专利」这个关键门。

## 9. 结论与建议的下一步

**一句话**：这个项目已经把最难的三件事想清楚并落了前两件半——逐段精读的防幻觉产物、刊物分级的诚实性、文件即真相源的门/降级体系；但它现在卡在「接线」和「最后两个领域」上。**不要先扩功能，先把已有价值接通，再按证据链补 M6/M7/专利。**

**建议顺序（也是我建议你拍板的顺序）**：
1. 批准 Phase 0 止血（5–7 人日），验收标准是「真 tectonic 出 PDF + 改名不丢节 + 限速跨实例有效 + 163+新测试全绿 + CI」。
2. 第 2 周上线「专利公开时序门 + 交底书 skeleton」（3–5 人日），在所有论文投稿/预印本上传前生效。
3. 并行推进 M6（可信写作）与 M7（实验/补数据），共用 metrics.json/claims.json 契约。
4. 专利 lite MVP 与查论文 L3 按资源穿插；最后做 M8 投稿返修与发布。

**如果现在就继续，我建议从 Phase 0 的 P0-1/P0-3/P0-5 开始**：这三处合计约 2.5 人日，却能把「论文线能不能真的产出 PDF」从「永远不能」变成「能」；随后再修 RateGate/OpenAlex（约 1–1.5 人日）。这也是所有后续里程碑的公共前提。
