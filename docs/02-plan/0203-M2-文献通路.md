**真网踩坑与勘误（重要度排序）**：

1. **arXiv 字段查询必须加引号**：`ti:attention is all you need` 裸空格返回 0 条；`arxivQueryField` 逐子句加引号、AND/OR 保留。
2. **arXiv Atom link 属性顺序无关**：真实 feed 是 `href` 在前（`<link href=… rel="related" type="application/pdf"/>`），按序正则永远失配 → pdfUrl 缺失。
3. **node lookup 回调双形态**：`http.request` 的 lookup 在 `options.all=true` 时要求 `(err, addresses[])` 地址对象数组；单值形式静默得到 `Invalid IP address: undefined`（钉死 IP 防重绑定的关键路径）。
4. **重复≠丢弃**：库 upsert 对已存在条目做信息补全（pdfUrl/oaUrl/citedByCount 回填 + seenIn 并集），否则首次无链接的条目永远取不到 PDF。
5. **RPC 错误信封必须带 details**（M1 遗留修正，见 661b759）。
6. 客户端解析字段与服务端返回形状要对齐——literature.search 返回裸数组，面板误读 `value.items` 恒 0 条（第二次踩同类坑）。
7. **工具输出必须无损 JSON**（597b4d1，桌面端用户实测发现，undefined/形状类第三刀）：`srw_literature` search 投影里显式写 `pdfUrl: item.pdfUrl` / `oaUrl: item.oaUrl`，可选字段为 undefined 时键被 JSON.stringify 丢弃 → 宿主校验 `value is not lossless JSON` → arXiv 源（从不设 oaUrl）search 100% 失败。修法照仓库守卫惯式条件展开，投影抽为 `searchOutputFor` 纯函数，并加 `assertLossless` 回归门（值树禁 undefined + JSON 往返等价 + 离线 fake 全动作过门）。

8. **import 参数会被 agent 剪薄，管线必须自愈**（undefined/形状类第四刀的变体——上游输入形状不可信）：桌面端实测 agent 组 import 参数只传 `source/arxivId/title`，剪掉 authors/year → 库里 year=0、authors=[]、citekey 退化 `unknownnd-*`（`firstAuthorSurname`→unknown、year→nd 双落空）。修复（597b4d1 之后的自愈提交）：① import 时带 arxivId 但 year/authors 不全的候选，入库前批量 `id_list` 拉权威元数据**只补空缺**（离线/失败不阻断，输出新增 `enriched` 汇报）；② upsert 重复条目 enrich 扩展补 year/authors——存量坏数据重导一次即愈（citekey/bibtex 是派生值，随之恢复；已落盘 PDF 文件名不变，纯外观）。
