# 0207 · M8 投稿与返修（修改循环 + 投稿包 + 格式检查）

> 设计源：[analysis/goals/02-写论文.md](../../analysis/goals/02-写论文.md) §5（5.1–5.7）与 §6 DoD-5/6/8、§5.7 验收 A8–A10
> 基线：main@167f1ce（2026-10-19；272 测试全绿 + CI 修复后重跑）
> 代码事实核对：本文件「附：当前代码事实」为本计划落地前实测（2026-10-19），行号以该时点为准

**目标（Goal）**：让论文生产线走完最后一公里——修改循环（快照标签/结构化 diff/回滚一致性）、审稿返修（审稿意见 → 带 diff 证据的响应信）、投稿包（D1–D3 分档的 manuscript/cover letter/highlights/declarations/checks）与格式检查（激活 venue 四个死字段）。

**架构（Architecture）**：延续「文件是真相源」——新增 `reviews/`、`submissions/`、`paper/diffs/` 三个落盘域；`src/writer/` 增 `diff.ts`（零依赖 Myers 纯函数）、`review.ts`、`submission.ts` 三个模块，经 WriterService 编排、srw_submission 工具与 paper.* RPC 暴露；UI 只做论文卡修订区与投稿卡。

**技术栈（Tech Stack）**：TypeScript（Node 24 / node:test）；零新依赖——diff 自实现，页数检测用系统 `pdfinfo`（缺席诚实降级），图片 DPI 用头部解析。

## 0. 执行约定（承接 0202–0206，含 10-19 凌晨新增教训）

1. **TDD**：每任务先写失败测试再实现；`pnpm typecheck` + `pnpm test` 全绿才 commit。
2. **大文件纪律**：`src/{service,tools,rpc}.ts`、`src/client/workbench.tsx`（67KB）一律 edit，禁止 write 整文件覆写（M5 期曾发生尾部截断）。
3. **单写者**：8.1–8.3 同域（writer/*）串行；8.4/8.5 可并行但落点文件互斥；多 agent 时写范围必须显式声明（M6/M7 两次并行覆写事故的铁律）。
4. **lib/ 同批**：改 src/ 必须 `pnpm build` 后 lib/ 与 src/ 同 commit（CI 有 `git diff --exit-code -- lib` 门）。
5. **环境缺席显式 skip**：无 tectonic → 真编译断言 skip；无 CJK 字体 → 渲染断言 skip（10-19 CI 首跑三红教训：skip 要显式声明原因，隐式依赖平台字体的测试必须加门）；skip 是设计不是失败。
6. **平台依赖进 ci.yml**：新引入的系统工具（如 poppler-utils）必须同步加进 workflow，并优先做成「缺席降级」而非硬依赖。
7. **诚实红线**：响应信证据门只证「引用存在」，不证「改得对」；pack 门只检测服务层写入——直写文件旁路需在 UI/文档明示（与 G1/G-M1 同源边界）。
8. **outputs/ 不入库**；提交信息中文、一事一 commit。

### 8.1 快照标签 + manifest 扩展（2026-10-19，commit 9445b45，CI 绿）

### 8.2 行 diff + paperDiff（2026-10-19，commit bde9459，CI 绿）

- 落地：`src/writer/diff.ts`（`diffLines` 纯函数；hunk 带 aStart/aCount/bStart/bCount + 行级 op；平局走 LEFT 使 hunk 内 `-` 在 `+` 前）；service.paperDiff（文本走行 diff、PDF 只比哈希，落盘 `paper/diffs/<from>__<to>.json` 幂等返回）；tools 增 `diff` 动作；rpc 增 `paper.diff`。测试 275→277。
- **有意偏离 ②**：算法用 **LCS 动态规划**而非本计划写的 Myers O(ND)——实现期推演发现 Myers 在「右移越出 a 末尾」时 x=N+1 溢出、回溯索引越界（a=[a]、b=[a,b,c] 即复现）；LCS 用 Uint8Array 方向矩阵（1B/格）简单正确有界，>8M 格（约 2800×2800 行）退化为整文件替换单 hunk 并保持诚实标注。
- 教训：管道 `pnpm typecheck | tail -1` 会吞退出码（`$?` 是 tail 的）——质量门取退出码必须紧跟无管道命令。

### 8.3 审稿意见→响应信（2026-10-19，commit 0593805）

- 教训：`Array.isArray` 会把 readonly 数组窄化成 `any[]`（TS 语义），回调参数需显式标注类型，否则 TS7006。

### 8.4 投稿材料草稿（2026-10-19，commit 2dca552）
