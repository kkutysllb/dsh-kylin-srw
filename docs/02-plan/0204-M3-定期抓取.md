## 2. 存储定位

订阅与游标落 **`<root>/.srw/watch.json`**（与 rate-ledger 同款：工作区文件即事实源、
原子落盘、过 `assertInsideRoot` 护栏；不动 srw_index 域 layout——域无迁移机制，
增表对存量文档的兼容风险不值得）。文档形状 `{schemaVersion:1, revision, subs:[]}`，
坏 JSON 抛 INVALID 不静默清空（同 library 口径）。

订阅模型：`{id, project, source, query, everySeconds(≥900), misfireGraceMinutes(默认30),
enabled, cursorMs, lastRunAt?, lastResult?{at,kind:'ok'|'error',fresh?,error?}}`。
