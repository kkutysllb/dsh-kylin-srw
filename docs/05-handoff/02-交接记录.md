## 6. 风险与红线（改代码前必须知道）

1. **凭据**：任何新代码不得读取 credentials.enc / credentials.key；hosts.json 只读不复制；日志与落盘不得含内网地址/用户名/端口（有单测扫描）。
2. **远端执行**：只用 argv 数组 + remoteLine 引号合成；脚本先 base64 落远端再 bash 绝对路径执行；绝不把用户值拼进命令串。
3. **不编造**：数字必须回指 metrics（claims/numbers）；未验证（formula、缺源）必须显式 unverifiable，不得假 pass；illustrative 默认拒绝。
4. **专利**：不构成法律意见、不预测授权、不自动提交；先申请后公开（公开时序门）；对比文件与实验数据不编造。
5. **提交**：outputs/ 与本插件无关，不要提交；.tools/ 已忽略；lib/ 必须与 src/ 同批（CI 有 git diff -- lib 门）。
6. **测试**：不要用 write 覆写 src/tools.ts 这类大文件（曾发生尾部截断）；大文件一律 edit。
